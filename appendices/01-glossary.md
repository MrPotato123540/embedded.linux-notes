## Terms added during chapter writing

This table covers terms used in section 03.10. The full glossary remains planned.

| Term | Meaning |
| --- | --- |
| APU | Application Processing Unit; the Cortex-A53 processor cluster |
| EL | Exception level; a CPU privilege level |
| FSBL | First Stage Boot Loader |
| HVC | Hypervisor Call; an instruction used to request an EL2 service |
| OP-TEE | Open Portable Trusted Execution Environment |
| PSCI | Power State Coordination Interface; standard CPU power services |
| SMC | Secure Monitor Call; an instruction used to request a monitor service |
| SMCCC | SMC Calling Convention; rules for firmware call arguments and results |
| TF-A | Trusted Firmware-A; the EL3 runtime firmware in this boot flow |
| TEE | Trusted Execution Environment |
| XMPU | Xilinx Memory Protection Unit |
| XPPU | Xilinx Peripheral Protection Unit |
| ZynqMP | Short name for Zynq UltraScale+ MPSoC |
