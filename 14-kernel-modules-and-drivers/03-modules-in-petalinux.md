# Adding Modules to a PetaLinux Project

> **Applies to:** PetaLinux 2024.1 · Zynq UltraScale+ MPSoC

**[14 · Kernel Modules and Device Drivers](README.md)** · Part VI: Linux Kernel and Drivers

## Recipe integration

The installed 2024.1 create tool exposes a `modules` subcommand. Use the template and recipe generated by that release, then keep the module source and configuration in maintained inputs.

The Yocto `module` class connects an external module to the kernel build. In-tree drivers are normally selected through kernel configuration fragments instead of a separate external-module recipe.

`KERNEL_MODULE_AUTOLOAD` lists modules that should load during startup. `KERNEL_MODULE_PROBECONF` and the related module configuration supply supported options. Loading policy does not install a missing module package; confirm image selection separately.

## Updating modules

Deploy modules with the kernel they were built for. Regenerate dependency information through the package/image flow. Keep rollback capable of restoring both kernel and modules together.

For a driver needed to mount root, prefer built-in support or include it in the early userspace environment. A module on the final root cannot load before that root is reachable.

> [!NOTE]
> **Not run on the reference setup:** creation, autoload and rollback of a new module package.
